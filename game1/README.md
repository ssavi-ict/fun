# Case File: Is This AI Generated?

A lightweight, web-based interactive detective game where players review text and image evidence to determine whether content was generated by Artificial Intelligence.

## Features

- **Interactive Investigation**: Test your perception against curated image and text evidence.
- **Dynamic Field Scoring**: Earn base points for correct verdicts and bonus points for solving without relying on hints.
- **Responsive & Accessible**: Includes dark/light mode toggle, keyboard hotkeys (`Y` for YES, `N` for NO, `Esc` to close modals), and accessible layouts.
- **Live Online Counter**: Integrates with Firebase Realtime Database for live active reviewer tracking.
- **Social Verdict Sharing**: Share final scores directly to Facebook, WhatsApp, X (Twitter), or copy share links to the clipboard.

## Tech Stack

- **HTML5 / CSS3**: Custom CSS variables, Grid layout, dark mode support, and keyframe animations.
- **Vanilla JavaScript (ES6+)**: Zero external JS framework dependencies.
- **Firebase Compat SDK**: Handles realtime presence.
- **Font Awesome CDN**: Vector icons for social sharing.
